# 全站知识库助手

登录后，在业务页面及 Django 管理后台右下角打开聊天气泡，或点击导航栏的「AI 助手」。
桌面支持紧凑面板和展开模式；手机根据可用视口显示面板。历史对话、原文引用、流式回答、停止回答和
数据分析继续使用原来的 RAG 功能。原 `/kb/ask/?conv=...` 链接会打开对应会话。

面板收起时保留对话页面与正在接收的回答；回答完成后入口出现提示。打开状态、展开状态和未发送草稿按
用户存入当前标签页的 sessionStorage。完整对话仍保存于既有 Conversation/Message 中，权限和部门隔离不变。
切换业务页面后，恢复当前会话并通过既有回答快照接回后台生成结果，不重新提交问题。

外壳由共享模板加载，首次打开才创建同源聊天视图。独立的聊天视图复用原有问答脚本，隔离各页面的 DOM、
CSS 及事件，避免与采集助手等页面冲突。Pyodide 改为在需要数据分析时加载，浏览普通页面不下载分析运行时。
原文引用通过验证来源的消息交给主页面的证据面板，PDF 页和定位框可使用完整屏幕。

仅允许同源嵌入。外壳和聊天视图均检查消息的 origin 与 source，未登录用户不显示助手。
移动端支持安全边距、可视视口变化、Escape 收起及模态焦点循环；减少动态效果的系统设置会关闭动画。
聊天视图常规链接在新标签页打开，下载与原文定位保持原行为。

验证覆盖全站入口、权限、懒加载、亮暗主题、桌面/手机/展开布局、中文输入法、流式回答、最小化提示、
原文定位、历史记录、跨页面恢复与草稿、停止及新建会话。浏览器检查使用合成回答，不调用真实模型。
